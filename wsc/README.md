# World Science Congress, 위대한 만남 — 스탬프 미션

전시품 5곳의 QR을 찍고 문제를 맞히면 시크릿 코드 글자를 하나씩 받아 **GREAT**를 완성하는 체험 페이지입니다.

- 미션 본부(시작): https://153nsm.github.io/test/wsc/
- 연구실: `…/wsc/?lab=jang|kepler|newton|curie|johnson`
- 설계와 규칙: [PLAN.md](PLAN.md)

## 카메라 켜기

모든 화면 맨 아래에 **카메라 켜기** 탭이 있습니다. 누르면 페이지 안에서 카메라가 켜지고,
미션 QR을 비추면 그 연구실(또는 미션 본부)로 바로 이동합니다. 미션과 상관없는 QR은 이동하지 않고 안내만 합니다.

- 휴대폰 브라우저의 QR 판독 기능(BarcodeDetector)이 있으면 쓰고, 없으면(아이폰 사파리 등) 같은 폴더의
  `vendor/jsQR.js`(jsQR 1.4.0, Apache-2.0, `vendor/jsQR-LICENSE.txt`)로 읽습니다. 외부 서버에 연결하지 않습니다.
- 처음 누를 때 카메라 사용을 허용해 달라는 창이 뜹니다. 거절했으면 휴대폰 기본 카메라 앱으로 QR을 찍어도 됩니다.

## 인쇄용 QR

`print/` 폴더에 A6 크기(300dpi) 카드가 있습니다. `wsc-qr-cards.pdf`는 6장을 한 파일로 묶은 것입니다.

| 파일 | 붙일 곳 | 글자 |
|---|---|---|
| `00-start.png` | 안내데스크·입구·미션 지도 | - |
| `01-jang-G.png` | 앙부일구 전시품 앞 | G |
| `02-kepler-R.png` | 케플러 연구실 (위치 미정) | R |
| `03-newton-E.png` | 피직스랩 프리즘 전시품 앞 | E |
| `04-curie-A.png` | 원자력 방사선 안전체험관 앞 | A |
| `05-johnson-T.png` | 인공위성·로켓·우주선 궤도 전시품 앞 | T |

문구나 주소를 바꾸면 다시 만듭니다: `pip install qrcode pillow` 후 `python3 wsc/tools/make_qr.py`

## 안내데스크 운영

1. 참가자 휴대폰의 미션 본부 화면에서 **시계가 움직이는지** 확인합니다. (캡처 화면은 시계가 멈춰 있음)
2. 코드 1개 이상 → 달력, GREAT 완성 → 랜덤 선물 뽑기.
3. 나눠 준 뒤 **직원용: 수령 확인 → 수령 처리**를 누르면 그 휴대폰에 기록이 남아 같은 휴대폰으로 다시 받을 수 없습니다.

## 한계

- 진행 기록은 휴대폰 브라우저에만 저장됩니다. 브라우저를 바꾸거나 사생활 보호 모드면 이어지지 않습니다.
- 서버가 없는 정적 페이지라, 소스를 뜯어보면 정답을 알 수 있고 다른 휴대폰으로 다시 참여할 수도 있습니다.
