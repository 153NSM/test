# 설문 집계기

엑셀에서 머리글 줄까지 복사해 붙여넣으면 문항별 결과 표(문항 / 유효 응답 / 평균 / 빈 응답 / 제외)를
보여 주는 한 파일짜리 페이지(`index.html`)입니다.

- 외부 라이브러리·외부 글꼴·분석 도구를 쓰지 않습니다.
- 붙여넣은 데이터는 브라우저 안에서만 계산하며, 밖으로 보내거나 저장하지 않습니다.

## 사용법

1. https://153nsm.github.io/test/ 를 열거나, `index.html`을 내려받아 브라우저로 엽니다.
2. 엑셀에서 머리글 줄을 포함해 표를 복사한 뒤 입력란에 붙여넣습니다.
3. 결과 표가 바로 나옵니다.

## 집계 규칙

- 첫 열(응답번호)은 집계하지 않습니다.
- 앞뒤 공백을 지운 값이 `1`·`2`·`3`·`4`·`5` 중 하나면 **유효**, 비었거나 공백만 있으면 **빈 응답**, 그 밖의 값은 **제외**입니다.
- 칸 수가 머리글보다 모자란 줄은 모자란 칸을 빈 응답으로 셉니다. 머리글보다 많은 칸은 무시합니다.
- 평균은 유효 응답의 합 ÷ 유효 응답 수를 소수 셋째 자리에서 반올림해 둘째 자리까지 보입니다. 유효가 0이면 `-`입니다.

자세한 설계는 [PLAN.md](PLAN.md)에 있습니다.

## 시험

Node.js 18 이상만 있으면 되고 설치할 것이 없습니다.

```bash
npm test
```

- `test/core.test.js`: `index.html`의 `<script id="survey-core">`(계산 로직)만 꺼내 규칙을 시험합니다.
- `test/page.test.js`: 외부 주소·전송/저장 API가 없는지, CSP와 표 머리글을 검사합니다.
- `test/browser.test.js`: Playwright가 설치돼 있으면 실제 브라우저로 붙여넣기 결과를 확인하고, 없으면 건너뜁니다.
